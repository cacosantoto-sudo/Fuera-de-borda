# Auxilio Fuera de Borda

App web (instalable en el celular) para diagnóstico de fallas y mantenimiento de motores fuera de borda.

Publicada en: https://cacosantoto-sudo.github.io/fuera-de-borda/

## Talleres adheridos

La lista de talleres está en `talleres.js`. Cada taller tiene su link (`?t=codigo`) y su kit imprimible con QR (`kit.html?t=codigo`). Contenido técnico: Scotto Mecánica Náutica.
